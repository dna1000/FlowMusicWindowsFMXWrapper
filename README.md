# Flow Music .fmx VST/CLAP Wrapper

## Overview

This is a VST3/CLAP wrapper for Google's Flow Music plugins with .fmx extension because they've not given us a Windows app yet.

It was coded with Antigravity Flash 3.8 High.

I've tested with a couple of basic .fmx files (included in the repo)

I've checked it loads and runs in Reaper and Bitwig but I haven't really tested anything and there are loads of files created by Antigravity as it ran. Feel free to copy the repo and use as you choose.

Use at your own risk.

## Installation

Download the FlowMusicWrapper.clap and/or FlowMusicWrapper_single.vst3 and save into your plugins folder.

Load the plugin and select load fmx from the top right.
